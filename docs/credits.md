# Credits

**Mechanica** is made by Open Linux Systems.

## Built with

- [Godot Engine](https://godotengine.org): the game engine (MIT licence).
- [Jolt Physics](https://github.com/jrouwe/JoltPhysics): rigid bodies and joints (MIT licence).
- [MoonSharp](https://www.moonsharp.org): the Lua interpreter that runs every part's behaviour.
- [.NET](https://dotnet.microsoft.com): C# and System.Text.Json.
- [Barlow and Barlow Condensed](https://github.com/jpt/barlow): the interface fonts, by Jeremy Tribby (SIL Open Font
  License 1.1, `game/fonts/OFL.txt`).

## Content

The parts, bots, quests, sounds and world in the `vanilla` mod are original to Mechanica. Mods you
install carry their own credits in their `mod.json`.

This page is `docs/credits.md`; edit it to add names.
